# Discord mark

`discord-clyde.svg` is Discord's official Clyde symbol, downloaded from the
[Discord brand page](https://discord.com/branding). It is used to identify the
Discord controls, without a word header. The mark belongs to Discord and is
not original Knobby artwork.

Source: https://cdn.prod.website-files.com/6257adef93867e50d84d30e2/66e3d80db9971f10a9757c99_Symbol.svg

The committed SVG allows icon regeneration without a network request.
