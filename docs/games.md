# Games

Home key **7** opens **Games**. The page has three launch buttons:

| Key | Button | Destination |
| --- | --- | --- |
| 2 | FFXIV | The existing FFXIV action: focus the running game or use its repaired regular Steam shortcut. |
| 3 | Decompbound | Run `make libretro-viewport-play` in `/home/monofuel/Documents/Projects/Sygnosphere/decompbound`, inside that project's `nix develop` environment. |
| 4 | Mono Retro | Run the installed desktop launcher, `/home/monofuel/bin/mono-retro`, with its existing library and configuration. |

Home remains on key **1**, Menu on **5**, and Back on **15**. Opening Games
does not start an application. These are normal editable button actions;
the FFXIV button reuses the existing launcher route rather than creating a
second Steam shortcut.

The Mono Retro wrapper currently selects the native menu under
`/mnt/steel-chest/Monolab/Home/racha/src/mono-retro/build/mono-retro`, the desktop
library at `~/anbernic/mono-retro-library-desktop`, and
`~/.config/mono-retro/library.json`. Knobby does not change those files, game
saves, the Decompbound launch target, or recording/audio settings.

To install the initial menu from the checkout, use
`nix develop --command nim r tools/setup_games_buttons.nim --apply`.
It uses the shared configuration validator, managed image imports and a fresh
revision-checked apply. Re-running it preserves subsequent editor changes.

The original pixel icons are generated by
`nix develop --command nim r gui/app/tools/generate_obs_icons.nim --games-only`.
They contain no extracted game imagery.

Decompbound's original sunset suburb and psychic planet use a chunky two-pixel
grid inspired by quirky suburban JRPG adventures. Regenerate only this icon with
`nix develop --command nim r gui/app/tools/generate_obs_icons.nim --decompbound-only`,
then install it with
`nix develop --command nim r tools/setup_games_buttons.nim --refresh-decompbound-art`.
This refresh changes only that launcher's managed image, preserves editor changes,
and requires no daemon or viewer restart.
